# Open Voice — documentation assets

This folder holds binary assets referenced by the project README.

## `screenshot.png`

The README embeds `docs/screenshot.png` as the hero image. Drop a fresh
screenshot of the running app here when the UI changes meaningfully —
the upstream Beingpax/VoiceInk hero image (previously linked from
`github.com/user-attachments`) is outdated for this fork.

Recommended capture:

- Window at 950×730 (the default minimum size) showing the Dashboard
  or History tab with at least one transcription rendered.
- macOS dark mode for parity with the icon’s color palette.
- PNG at 2× / Retina (1900×1460 logical) so the embed scales cleanly
  on high-DPI displays.

Replace the file in place and commit. The README link auto-picks up.
